# 曲庫候選清單說明

清單檔：`song-candidates.csv`（可用 Excel 直接開啟），共 502 首，不含遊戲裡已有的 34 首。

## 版權狀態怎麼算（以 2026 年為準）

| 地區 | 規則 | 可用條件 |
|---|---|---|
| 台灣 | 作者過世後 50 年 | 作曲者 1975 年以前過世 |
| 歐盟 | 作者過世後 70 年 | 作曲者 1955 年以前過世 |
| 美國 | 依發表年份 | 1930 年以前發表 |

傳統曲（作者不詳）視為各地都可用。

## 狀態欄

| 狀態 | 首數 | 意思 |
|---|---|---|
| 全球可用 | 378 | 三地都已無版權 |
| 全球可用（需確認備註） | 63 | 規則上可用，但作者歸屬、年份或常見版本有疑慮，見備註 |
| 台灣可、部分地區有版權 | 28 | 台灣可用，但美國或歐盟仍有版權；若上架全球商店，這些要避開或分區 |
| 年份待查 | 4 | 作曲者卒年不明，查清前不要用 |
| 有版權 | 29 | 不能用（另含政治敏感、建議避開的曲目） |

## 注意事項

- 年份是依據一般資料整理，未逐首查證原始文獻。正式收錄前，「需確認」與「台灣可、部分地區有版權」的曲目要再查一次。
- 只用旋律，不用歌詞，也不用別人的錄音。若使用他人的編曲或 MIDI 檔，該檔案本身的授權另外確認（例如 Mutopia 的 CC 授權）。
- 法國對部分作曲家有戰時延長保護（例如拉威爾〈波麗露〉），歐洲上架前要留意。
- 鄧雨賢的〈望春風〉〈雨夜花〉等在台灣已無版權，但 1930 年後發表，美國仍受保護到發表後 95 年。
